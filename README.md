# ZETA — График регионов

Статическое веб-приложение для планирования регионов и контроля дат. Работает без сборки и без внешних JavaScript-библиотек.

## Файлы
- `index.html` — интерфейс приложения (UTF-8).
- `styles.css` — оформление.
- `app.js` — логика, локальное сохранение, CSV и печатный PDF-отчёт.

## Запуск
Распакуйте архив и откройте `index.html` в современном браузере. Для публикации на GitHub Pages загрузите все три файла (`index.html`, `styles.css`, `app.js`) в корень репозитория и включите Pages в Settings → Pages.

## Экспорт PDF
Нажмите «Скачать PDF». Приложение откроет отдельную страницу отчёта и вызовет встроенное окно печати браузера. В качестве принтера выберите **«Сохранить как PDF»** (на телефоне — системное меню печати/сохранения в PDF). Этот способ не требует интернета и сторонних библиотек, поддерживает кириллицу через Unicode и не создаёт пустой лист из-за html2pdf/html2canvas. Если браузер блокирует новое окно, разрешите всплывающие окна для сайта и нажмите кнопку снова.

## Экспорт CSV
Кнопка «Экспорт CSV» сохраняет данные в CSV с UTF-8 BOM, чтобы кириллица корректно открывалась в Excel.

## Сохранение данных
Записи сохраняются в `localStorage` текущего браузера и устройства. Автоматической синхронизации между разными устройствами нет. Перед очисткой данных рекомендуется экспортировать CSV.
